    System Information Inventory (CLI + GUI)

    Audience: IT Admin / Student System: macOS Last reviewed: 2026-02-03

    This article documents a Mac system inventory snapshot (OS, CPU, motherboard/logic board, RAM, storage, GPU) and the corresponding Terminal commands to retrieve each item for repeatable verification.

    Good for
    Quickly capturing system specs for documentation, troubleshooting, and lab submissions using both GUI evidence (screenshots) and CLI verification commands.
    Be careful
    Some commands may reveal identifying details (serials, disk layout). Share outputs only with trusted parties and redact sensitive identifiers when posting publicly.

    How To Use Terminal To Find:

    OS

    sw_vers

    CPU

    sysctl -n machdep.cpu.brand_string

    RAM

    system_profiler SPMemoryDataType

    Storage

    diskutil list

    GPU

    system_profiler SPDisplaysDataType
